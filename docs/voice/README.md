## 3. การใช้งานในแอป

- **เตือนแบบเดียว:** พอใช้แอปเกินเวลาที่ตั้งไว้ จะขึ้นแจ้งเตือน สั่น และเล่นเสียง 1 ประโยคทันที ถ้ายังใช้ต่อจะเตือนซ้ำทุก 5 นาที (โหมดสาธิตทุก 20 วินาที) และหยุดเมื่อออกจากแอปนั้น
- **ข้อความตรงกับเสียง:** ข้อความในแจ้งเตือนคือประโยคที่พูด (`R.array.roast_voice_lines` ลำดับเดียวกับไฟล์) สุ่มตามภาษาของแอปและไม่ซ้ำกับครั้งก่อน
- **ไม่มีเสียงเมื่อ:** เครื่องปิดเสียง สั่นอย่างเดียว เปิดห้ามรบกวน หรือปิดสวิตช์ ตั้งค่า > การเตือน > เสียงพากย์ตอนเตือน (ค่าเริ่มต้นเปิด) แจ้งเตือนกับการสั่นยังทำงานตามปกติ
- **ปัดแจ้งเตือนทิ้ง:** หยุดเสียงที่กำลังเล่น แต่ยังเตือนครั้งถัดไปตามรอบ
- **ฟังตัวอย่าง:** ตั้งค่า > ตัวอย่างการแจ้งเตือน มีปุ่มฟังเสียงกับประโยคถัดไป เล่นได้แม้เครื่องปิดเสียง และเตือนถ้าเสียงนาฬิกาปลุกตั้งไว้เบา
- **โค้ด:** `VoiceClips` (จับคู่ไฟล์กับประโยค), `VoiceRoastAlert` (จังหวะการเตือนและการเล่น), `ReminderPreviewUi` (หน้าตัวอย่าง)

### ความดัง (16 พ.ย. 2026)

- **เล่นผ่านระดับเสียงนาฬิกาปลุก** (`USAGE_ALARM`) ไม่ใช่เสียงสื่อ เพราะคนมักลดเสียงสื่อไว้ตอนไถฟีด ทำให้เสียงเตือนเบาตามไปด้วย หน้าตัวอย่างใช้เส้นเสียงเดียวกัน จึงดังเท่าการเตือนจริง
- **ไฟล์เสียงเพิ่มแค่ระดับเสียง:** แต่ละไฟล์คูณเกนคงที่ค่าเดียว (0.8–3.7 dB) ให้ยอดคลื่นอยู่ราว -1.4 dBFS ไม่มี compressor หรือ limiter จึงไม่เปลี่ยนรูปคลื่น ผลคือ -16 ถึง -19 LUFS และไฟล์ไทยดังใกล้เคียงอังกฤษ (เดิมไทยเบากว่าราว 2 dB) `roast_en_05` กับ `roast_en_08` ยอดคลื่นชิดเพดานอยู่แล้ว จึงเป็นไฟล์ต้นฉบับไม่ได้แตะ ไฟล์ที่ปรับเข้ารหัสใหม่เป็น MP3 mono 96 kbps ที่ sample rate เดิม
- **อย่าดันให้ดังกว่านี้ด้วยการบีบอัดเสียง:** เคยลอง compressor + limiter ไปที่ -12 LUFS แล้วเสียงแตก ถ้าต้องการดังกว่านี้ให้อัดเสียงใหม่ให้ดังตั้งแต่ต้นทาง
