# Name and icon concepts

Two proposals for “วางเดี๋ยวนี้! / Put It Down!”. Selected: the second concept, Exclamation, coral on cobalt. The app prototype and Android launcher now use this identity. The Arrow concept is retained only as exploration history.

- Arrow + dot: horizontal bilingual wordmark, coral tile and a downward arrow ending above an exclamation dot.
- Exclamation: stacked Thai wordmark and a coral exclamation on cobalt.

The SVGs are editable vector sources. Wordmark text remains editable text, not converted to outlines; install Noto Sans Thai and Manrope to reproduce the intended typography in a vector editor. Icon SVGs use only geometry and do not depend on fonts. Adaptive-icon foreground/background and monochrome Android resources would be a separate implementation step.

The preview shows 36px header icons and 48px / 24px icon checks in both background themes. Browser screenshots are design references, not Android launcher tests. Shapes were created for this proposal with AI assistance. Font licenses are described in the parent design README.
